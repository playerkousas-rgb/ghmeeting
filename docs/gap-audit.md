# 🔍 全 APP「叫你做 → 有冇教你點做」審計

> 2026-09-04。起因：負責人一句「很多手工都說先睇成品，問題是我是新領袖自己也不會做」。
> 於是將同一把尺量化成一份審計：**APP 每叫領袖做一件事，係咪同時俾到「人手／份量、做法、工具、範本、後備」其中一樣？**
> 判斷尺度（負責人指定）：「準備紙筆」呢類任何成人都識嘅嘢，唔算缺口，唔使改。

## 1. 方法（點樣量）

1. 將全站每個「要求」按**單位**列出（一個單位＝一個環節 `how`+`script`＋對應 `Guide` 指引＋手工自學卡＋物資清單），唔係逐行 grep。
2. 對每個單位問四題：
   - 有冇**數量／尺寸**（每人幾多、剪幾長、幾多分鐘）？
   - 有冇**步驟**（ numbered steps 或畫面演示）？
   - 有冇**現成嘅屏／範本／工作紙**可以直接用？
   - 出錯／做唔切嗰陣，有冇**後備**？
3. 四題全部冇 ＋ 件事唔係「成人即知」→ 列入缺口。
   （注：最初用純正則掃出 545 條候選，全部短 `lead:`/`say:` 都被誤報——單位級先至係正確嘅粒度。）
