# 🦗 小童軍團集會助手 — 產品定位及目標(v2 重做藍圖)

> 2026-09-04 與負責人對齊確認。此文件為 v2 重寫之依據,舊版 `grasshopper-kit.html` 之功能以此文件重新取捨。

## 1. 一句話定位

**「由年度計劃到散會嗰刻」的小童軍團集會副機**——
不止是內容庫,而是**行動工具**:開季規劃 → 執集會 → 當日投影帶領 → 事後追蹤團員進度,一條龍。

對官方《小童軍團集會套包 2026v2》要做到:**「唔止睇得到,仲跟得到、改得到、追到數。」**

## 2. 要打贏嘅對象(參考資料分析)

總會發展署《小童軒團集會套包 2026v2》三大核心及其限制:

| 官方套包有 | 官方套包做唔到(= 我哋嘅價值) |
|---|---|
| 22 次年度行事曆範本(8-9月→6-8月) | 行事曆係死表格,唔可以按旅團實際情況調動、順延、補集會 |
| 團員章+進步獎章首年集會編排 | 只有第一年;22個月進步獎章後段 + 18個月小草蜢獎章完全冇跟進 |
| 程序表+活動建議卡+物資清單 | 靜態頁面:冇計時、冇投影、冇講稿提示、冇搜尋、唔可以改 |
| YouTube 參考連結 | 要上網、集會中途跳出去搵片好尷尬 |
| 填寫式日期/領袖表格 | 要印出嚟先填到,冇紀錄、冇延續 |

**結論:官方資料只作學習邊界，不搬版面、不逐頁重現。產品入口改為「今日就可以帶」：每個活動由我們重新編成準備卡、圖解、口令、節奏及安全提示，領袖不需要對照參考資料才可開始。**

## 3. 目標用戶(並重)

1. **新晉領袖**(首要關照):跟住做就掂——現成全年課表、每環節講稿提示、物資自動埋單,零準備都可以帶一次完整集會。
2. **資深領袖**:即用工具箱——大字投影、計時、分組計分、獎章追蹤、快速改動/自製集會。
3. (次要)家長義工/協助人士:看得懂的當日流程,降低幫手門檻。

## 4. 核心用戶旅程(四段,全部要落地)

```
① 開季規劃 ──→ ② 執集會 ──→ ③ 當日帶領 ──→ ④ 事後追蹤
   年度行事曆      環節積木        投影+計時+講稿     團員進度
   (42個月路線)   +物資自動       +遊戲/儀式大卡     +集會紀錄
                  埋單清單
```

### ① 規劃 Plan
- 全年行事曆:以官方 22 次範本為底,可調動/順延/跳過/補集會,自動對齊節日(中秋、農曆年、創辦人紀念日、母親節…)
- **42 個月完整路線圖**:團員章(4次集會)→ 四級進步獎章(紅/啡/藍/綠,約22個月)→ 小草蜢獎章(七大範疇×2體驗,約18個月),唔會做完第一年就斷
- 旅團資料設定:集會日/時長(預設40-60分鐘)/團員名單

### ② 執集會 Prepare
- 22+ 次官方對齊範本課表(恆常+特別+戶外)+ **自製編排器**(環節積木:儀式/課程/遊戲/美勞/故事/唱遊/…,分鐘可調)
- 每次集會自動產出:**物資總清單**(可勾選)+ 環節流程 + 負責領袖分工
- 分享:一個 link/文字俾其他領袖看到成次集會

### ③ 帶領 Lead(現場,最大差異化)
- 投影模式:誓詞/規律/主題曲(寄調 London Bridge)大字卡、快樂傘玩法卡、遊戲畫面、倒數
- 領袖欄(手機/另一畫面):進度+「而家講咩」講稿提示+下一環節預覽+計時
- 即用工具:抽籤、分組、計分板、大聲倒數、音效
- 4-7歲節奏設計:每 5-10 分鐘一轉、動靜交替、靜息呼吸收尾

### ④ 追蹤 Track
- 團員名單:每人 badge 進度(團員章三項 ✓ / 進步獎章四級 / 小草蜢七大範疇體驗 ✓×2)
- 集會紀錄:出席、當日完成嘅獎章要求(自動落到團員度)
- 匯出:文字/CSV 俾團長交報告用;資料只存本機

## 5. 內容方針

- **依據**:《小童軍活動指引》第三版(2026年8月、2026-08-15 生效)之訓練綱要
- 內容以綱要為邊界，活動由本工具**自行撰寫及重新編排**；不照搬官方套包版面或逐段說明，閱讀時以準備卡、圖解、領袖口令和現場互動為主

## 6. 形態及技術

- **PWA 網站**:一個 URL 開即用、可「加至主畫面」、Service Worker 離線可用、可持續更新
- 資料**本機優先**(localStorage/IndexedDB),不上傳;單機運作完全正常
- 部署:GitHub Pages(免費、穩定)
- 手機/平板/投影瀏覽器全部支援;廣東話書面並用(貼近香港領袖習慣)

## 7. 成功指標(點為之「好過官方套包」)

1. 新領袖由開 APP 到帶到第一次完整集會:**≤ 3 分鐘準備**
2. 任何一次範本集會可以**10 秒內開始投影帶領**
3. 官方套包 22 次集會內容 100% 有得睇之餘,每一次都**改得到、帶到、記到數**
4. 進度追蹤令團長**唔使再靠記憶/Excel** 知邊個差幾多完成小草蜢獎章

## 8. 明確唔做(Scope 外)

- 不做會員系統/雲端帳號(本機優先,日後先考慮)
- 不做多支部(幼童軍等)——專注小童軍做深
- 不代替官方紀錄/核准;app 內標明「非官方輔助工具,一切以香港童軍總會公佈為準」
