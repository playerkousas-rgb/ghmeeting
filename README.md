# 🦗 小童軍集會助手

**© 2026 Scout System**｜非官方輔助工具，一切以香港童軍總會公佈為準。

**目標：取代官方團集會套包。** 新領袖只要呢個 APP，就帶得完整場集會，唔使再翻官方 PDF。
官方套包俾你「睇」，呢個 APP 俾你「帶」，甚至幫你帶。

```
🅰️ 上方（新手跟住做，一場集會四步）   1 📅 揀集會 → 2 🖨️ 印教材 → 3 ▶️ 帶領 → 4 🏅 記錄
🅱️ 下方（工具箱，老手直接撳）        ✂️ 圖紙 ｜ 🎮 活動 ｜ 🧩 範本 ｜ 📖 手冊
```

上下各**最多 4 個掣**，細部電話都放得曬；上方係「照住做」嘅流程，下方係「想要邊樣攞邊樣」嘅工具。

```

 ├─ 🖨 只印三樣：✂️ 小朋友圖紙・📐 貼地圖紙・📋 領袖一頁流程
 └─ 📱 其餘喺 APP：執袋單・帶領卡・自學卡・設場・檢查表・家長通知・嘉許狀
```

## 圖紙喺邊度搵？（三條路，條條通）

1. **下方工具箱「✂️ 圖紙」** —— 全部圖紙／場地圖卡／教案／海報都喺呢頁，第一格就係「今場要用嘅圖紙」。
2. **套包頁（🖨️ 印教材）** —— 頂部寫住「✂️ 今場圖紙（N 款）」，撳「🖨️ 印齊今場」＝教案打頭陣、**圖紙自動跟喺後面**，中間夾一張分隔頁。
3. **教案紙本身** —— 每份教案最底自動印一張「✂️ 今場圖紙清單」：印幾多份、邊個環節用，一眼睇晒。

## 三步開始

1. 開網址 → 瀏覽器 menu →「加至主畫面」（離線都用得）
2. 上方「2 🖨️ 印教材」→ 撳「🖨️ 印齊今場（教案＋圖紙）」，一次過印晒
3. 到場撳「▶ 即開帶領」，跟綠色領袖欄一步一步做；完場記出席，進度自動入「4 🏅 記錄」

## 環保：淨係印要印嘅

預設只印三樣 —— 小朋友圖紙（要剪要摺）、貼地圖紙（要黐地下）、領袖一頁流程（帶隊手要空）。
其餘 7 樣喺 APP 睇到、剔到、複製到，唔使白印。

- 未填名單預設印 **1 份**（唔會白印 12 份）
- 小朋友圖紙**逐款揀**：護照、名牌呢類一次過嘅紙可以剔走，下次先印
- 想多印邊樣，喺套包頁剔返就得

## 兩疊紙，點解要分開

以前手工紙同說明書印埋一疊，剪唔落手。而家：

| | 邊個睇 | 內容 |
|---|---|---|
| ✂️ 即用紙 | 小朋友 | 一張紙一件事：剪線／摺線／描紅／塗色格，A4 實際尺寸，印完即用 |
| 📚 自學卡 | 領袖 | 逐步拆解・最易錯位・補救・後備版・4–7 歲控場（開會前 3 分鐘睇） |

15 樣手工全部有即用紙；未收錄嘅手工自動跌入「今日我整咗……」萬用纸。

## 資深領袖：唔使跟四步

- **🅱️ 下方工具箱**：想印嘢撳「✂️ 圖紙」、想玩嘢撳「🎮 活動」、想抄場撳「🧩 範本」、想查嘢撳「📖 手冊」
- **⚡ 臨時集會**（套包頁）：揀個主題（安全／健康／環保／體能／綜合），即刻砌好一場，套包照印、畫面照帶
- **⚡ 隨手開會**（右上角）：零物資即開即帶，另有吹哨／抽籤／分組／計分快鍵
