# 🦗 小童軍集會套包(Grasshopper Kit)

**© 2026 Scout System**

**一個檔案就是整個套包:`小童軍集會套包.html`** —— 唔使安裝、唔使上網、冇廣告。唔係紙本說明書,係可以直接投影、直接帶領嘅互動工具。

## 🎯 三種用法・總有一種啱你
- **🎖️ 資深領袖** — 現成工具即用:遊戲樂園、領袖工具、手冊,想用邊樣撳邊樣
- **📚 新領袖跟住做** — 12次編好嘅課表(可讀版);「▶直接帶領」=全自動(點名帶到散會);「集會流程台」=半自動(自己轉環節、自動計時)
- **🛠️ 自製集會** — 編排工具:19種環節積木+自訂環節,砌自己嘅集會,儲存到「我嘅集會」、匯出文字分享俾其他領袖、即刻▶帶領

## ⚡ 帶領模式細節
**① 新領袖直接 PLAY** — 首頁撳「📚 揀一次集會・即刻PLAY」→ 撳「▶ 直接帶領」→ 撳「🖥️ 全螢幕」。內置 **12 次編好嘅集會課表**(第1–4次=新團員玩到攞團員章;第5–12次對應進步獎章+德智體群美),每次由點名帶到散會+冠軍榜,連「🎤 而家講咩」提示都有,物資清單亦列明。

**② 集會前溫書/自訂** — 「⏱️ 集會流程台」可加減環節改分鐘;「📖 手冊」有誓詞規律主題曲+支部速覽;「📚 快速上手」兩分鐘睇晒點帶。任何課表可「載入流程台」修改後再帶領。

帶領模式大畫面投影俾小朋友(誓詞大字、卡拉OK歌詞、遊戲、對錯法庭、快樂傘玩法卡、靜息呼吸);底部綠色領袖欄顯示進度+講稿提示+倒數;全場只需要撳「下一個 ▶」。

## 點用(30秒)
1. 下載 `小童軍集會套包.html`
2. 用任何瀏覽器打開(手機/平板/電腦都得)
3. 想方便啲?瀏覽器 menu →「加至主畫面」,之後一撳就開

## 手動工具(唔用帶領模式都得)
- **⏱️ 集會流程台** ─ 60分鐘標準流程自動計時,分鐘可加減,每節可獨立「▶ 帶領」
- **🎮 遊戲樂園** ─ 領袖話、紅綠燈、記憶配對、捉草蜢、問答擂台(36題)、節奏模仿、估估下、對錯法庭(善行+Safe from Harm)
- **🧰 領袖工具** ─ 抽籤轉盤、隨機分組、計分板、大聲倒數、音效板、靜息呼吸
- **📖 支部內容** ─ 誓詞/規律/主題曲大字卡、團員章+進步獎章追蹤(可匯出)、快樂傘12式、律動指令機、故事寶盒

## 資料依據:官方《小童軍活動指引》第三版(2026)
小童軍支部嘅「訓練綱要」=《小童軍活動指引》(因為不設考驗,所以唔叫訓練綱要)。1987年初版→2009年第二版→**2026年2月第三版(2026-08-15生效)**,共40頁,四章+附錄:
- 第一章 組織及規條(目的「認識自己・快樂同行」、誓詞/規律/**口號「小童軍向前進」**/銘言「前進」、4-7歲、領袖比例)
- 第二章 訓練計劃(團員章 → 進步獎章4級約22個月 → **小草蜢獎章**:6歲起小草蜢歷險,七大範疇各2項體驗,銜接幼童軍體驗章)
- 第三章 典禮與儀式(快樂傘開始/結束儀式、宣誓儀式全文、晉團儀式)
- 第四章 快樂傘 + 附錄(官方遊戲、Safe from Harm 教材、七大範疇活動建議)
- 官方下載:sites.google.com/scouting.org.hk/grasshopper

套包已按第三版全面對齊:官方口號銘言、小草蜢章追蹤(7範疇×2體驗)、宣誓禮投影環節、官方快樂傘遊戲、進步獎章月份。
