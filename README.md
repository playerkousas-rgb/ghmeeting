# 🦗 小童軍集會助手 Grasshopper Hub

**© 2026 Scout System**

**由年度計劃到散會嗰刻**——規劃 → 執集會 → 當日帶領 → 團員進度追蹤,小童軍團集會一條龍工具(PWA,一個網址開即用、可加至主畫面、離線都用得)。

## 🧭 四段旅程(五個分頁)

| 分頁 | 做乜 |
|---|---|
| 📅 **規劃** | 年度行事曆(首年22次,可換範本/記完成)+ 42個月完整路線圖(團員章→紅啡藍綠四步→小草蜢七大範疇→晉團) |
| 🧩 **集會** | 30個範本(以《小童軒活動指引》第三版綱要編寫)+ 編排器(20種環節積木/自訂環節)+ 物資自動埋單 + 分享文字 |
| ▶️ **帶領** | 全螢幕投影:誓詞大字、主題曲卡拉OK、快樂傘儀式/玩法卡、11種遊戲畫面;綠色領袖欄=計時+🎤講稿提示+下一環節;6件即用工具(抽籤/分組/計分/倒數/音效/靜息呼吸) |
| 🏅 **追蹤** | 團員名單、團員章6項、進步獎章四步、小草蜢7範疇×2體驗;完成集會即記出席+自動落badge;一鍵匯出報告 |
| 📖 **手冊** | 誓詞/規律/口號/銘言、主題曲、獎章制度、快樂傘16式、Safe from Harm、4-7歲帶領貼士 |

## ⚡ 30秒開始

1. 開網址(GitHub Pages)→ 瀏覽器 menu →「加至主畫面」
2. 📅規劃 → 撳「▶ 帶領下次集會」→ 全螢幕 → 跟住綠色欄撳「下一個 ▶」就帶完成次集會
3. 集會完撳「✓ 記錄完成」→ 剔出席 → 進度自動入 🏅追蹤

## 🔒 資料

- 團員資料/集會紀錄**只存在你自己裝置**(localStorage),不上傳
- Service Worker 離線快取,冇網都用得
- 此為非官方輔助工具,一切以香港童軍總會最新公佈為準
