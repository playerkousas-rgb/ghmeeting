## 三步開始

1. 開網址 → 瀏覽器 menu →「加至主畫面」（離線都用得）
2. 📦 套包 → 撳「🧒 印小朋友紙」（自動印夠人數）＋「🧑‍🏫 印領袖套包」（1 頁）
3. 到場撳「▶ 即開帶領」，跟綠色領袖欄一步一步做；完場記出席，進度自動入 🏅追蹤

## 環保：淨係印要印嘅

預設只印三樣 —— 小朋友剪摺紙（要剪要摺）、貼地標記（要黐地下）、領袖一頁流程（帶隊手要空）。
其餘 7 樣喺 APP 睇到、剔到、複製到，唔使白印。

- 未填名單預設印 **1 份**（唔會白印 12 份）
- 小朋友紙**逐款揀**：護照、名牌呢類一次過嘅紙可以剔走，下次先印
- 想多印邊樣，喺套包頁剔返就得

|---|---|---|
