上下各 **5 個掣**，細部電話都放得曬。

- **🅰️ 上方係「指引」（我仲未想好做乜）**：📅 集會目錄＝22 次集會目錄＋時程，**成條行任何位置都撳得＝即刻入嗰場嘅 STEP BY STEP 預備**（淨係狀態標籤例外，撳佢改完成／跳過／日期）；🧩 範本＝30 場即用範本（撳標題一樣入逐步預備）；▶️ 帶領；📦 官方套包＝香港童軍總會《小童軍團集會套包》逐項對照（程序・物資・教學參考・紙模型・行事曆，每項一撳跳去本 APP 對應版）＋一撳印齊＋📚 手工自學卡（抽上嚟做正面位）；📖 手冊＝小童軍核心內容（核心・獎章制度・保護自己・帶領貼士・關於）。
- **🅱️ 下方係「即插即用」（我知我要乜，直接搵）**：集會途中先至會撳嘅嘢——**突然想加個節目，撳一下就開**，唔使準備、唔使印嘢、唔放「今場」準備條。

## 🧭 撳住場，STEP BY STEP 預備（唔係一堆資料）

**原則（負責人）**：撳進按鈕唔可以仲要自己諗「而家應該做乜」。揀好場，APP 一步步帶你：

```
① 揀集會 → ② 印教材 → ③ 執袋 → ④ 設場 → ⑤ 帶領 → ⑥ 記出席 → 🎉 散會
```

- **入口**：「📅 集會目錄」或「🧩 範本」撳任何一場嘅**標題** → 即時入逐步預備頁（`#prep`）。
- **預備頁**：一步一張卡——而家做乜・點解要做・撳邊個掣做；完成收做 ✓ 細行，未做減淡。印咗／執齊／帶完**自動標 ✓**，彈出下一步；收咗機返嚟都接得返。
- **想睇堆資料**先至撳「📋 睇全部資料」（物資總表・分工・家長訊息・逐節流程）——唔係預設。
- 喺其他頁行緊預備，底部嚮導條跟住你（📋 返預備頁）；「✕ 收埋嚮導」完全退出。

```
📦 集會套包（🖨️ 印教材）
 ├─ 🖨️ 印齊今場＝領袖教案 →（分隔頁）→ ✂️ 小朋友圖紙　※一疊過印，圖紙唔會失蹤
 ├─ 🖨 只印三樣：✂️ 小朋友圖紙・📐 貼地圖紙・📋 領袖一頁流程
 └─ 📱 其餘喺 APP：執袋單・帶領卡・自學卡・設場・檢查表・家長通知・嘉許狀
```

## 圖紙喺邊度搵？（三條路，條條通）

1. **下方「✂️ 工作紙」** —— 純教材庫：全部工作紙／圖紙／場地圖卡／教案／海報都喺呢頁（今場要印咩 → 上方 📦 官方套包一鍵印齊）。
2. **套包頁（🖨️ 印教材）** —— 頂部寫住「✂️ 今場圖紙（N 款）」，撳「🖨️ 印齊今場」＝教案打頭陣、**圖紙自動跟喺後面**，中間夾一張分隔頁。
3. **教案紙本身** —— 每份教案最底自動印一張「✂️ 今場圖紙清單」：印幾多份、邊個環節用，一眼睇晒。

## 三步開始

1. 開網址 → 瀏覽器 menu →「加至主畫面」（離線都用得）
2. 「📅 集會目錄」撳住你要帶嗰場 → **STEP BY STEP 預備**：印教材 → 執袋 → 設場，一步一格，做咗自動計
3. 到場跟逐步預備撳「▶ 即開帶領」，跟綠色領袖欄做；完場記出席，進度自動計

## 環保：淨係印要印嘅

預設只印三樣 —— 小朋友圖紙（要剪要摺）、貼地圖紙（要黐地下）、領袖一頁流程（帶隊手要空）。
其餘 7 樣喺 APP 睇到、剔到、複製到，唔使白印。

- 未填名單預設印 **1 份**（唔會白印 12 份）
- 小朋友圖紙**逐款揀**：護照、名牌呢類一次過嘅紙可以剔走，下次先印
- 想多印邊樣，喺套包頁剔返就得

## 字要少，步驟要列點

- **步驟就係 1 → 2 → 3**：每個環節得三步，大字、有次序、有圖標；領袖照住行就啱。
- **介紹得一句**：每頁開頭一句講完（「想唱就唱，唔使搵片」），長篇全部收埋。
- **長文要撳開**：留意・安全・物資點備・檢查表全部摺埋，要用先撳開——唔會一開波成版字。
- **列表最多兩行**：活動／玩法卡只出重點（CSS clamp），全文喺撳入去嗰張卡。
- `tests/smoke.js` ⑳ 守住上限：任何一頁爆字數、步驟唔按次序，測試會 fail。
- **🧩 #meet 定流程 2646 → ~1700 字**：30 張範本卡淨出「名・分鐘・節數・▶ 帶領」，主題／印教案／改內容收埋落「內容・其他」。
