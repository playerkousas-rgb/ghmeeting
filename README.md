## ⚡ 30秒開始

1. 開網址(GitHub Pages)→ 瀏覽器 menu →「加至主畫面」
2. 📅規劃 → 撳「▶ 帶領下次集會」→ 全螢幕 → 跟住綠色欄撳「下一個 ▶」就帶完成次集會

## 🎮 遊戲：螢幕帶領，小朋友身體落場玩

**我哋唔係打電子 GAME。**十幾個小朋友圍住一部機搶住撳，只會打架—所以每個遊戲都改成：

> 螢幕只係幫領袖**出題・叫位・計時・計分・播拍子**；遊戲本身係小朋友喺場內用身體玩，領袖撳掣。

| 遊戲 | 小朋友做乜（身體） | 領袖撳乜 |
|---|---|---|
| 🦗 **草蜢跳格・實體九宮格** | 地上 3×3 九宮格，聽到「幾號・邊個位」就限時跳上去 | 「▶ 叫格」→ 倒數 →「✓ 站到咗／✗ 未去到」記分；**秒數（1–30）、回合數、全體跳／分組接力全部自訂** |
| 🏆 **問答擂台・四角搶答** | 行去 A／B／C／D 角企好 | 「🎲 下一題」「✅ 揭曉答案」＋隊名記分 |
| 👍 **對錯法庭・左右分邊** | 行去 👍 或 👎 嗰邊表態 | 「⚖️ 宣判」＋請一位講原因 |
| ♻️ **三色回收・四角分桶** | 行去藍／黃／綠／⬛ 桶角 | 撳正確嗰個桶揭曉＋講回收貼士 |
| 🃏 **記憶配對・口講位置** | 用口講「第 3 張同第 8 張」 | 揭卡（卡有編號先講得到） |
| 🌕 **中秋射月・真實投擲** | 企喺投擲線後拋泡棉球 | 「🎯 中咗 +1」「❌ 冇中」「🙋 下一位」 |
| 🎵 **節奏模仿・跟拍子** | 跟住真實拍子聲做動作 | 揀 80／100／120 BPM、「▶ 播出節奏」 |
| 🚦🙋🎤🌈 紅綠燈・領袖話・傳球點名・快樂傘 | 行、定格、圍圈傳球、揚傘 | 轉燈／出指令／停球／抽一式 |

- 📖手冊新增 **「🎮 遊戲帶領總表」**：22 個遊戲一頁睇晒，撳「▶ 即開」直接投影
- 🖨️教材庫新增三份實體教具：**九宮格地貼＋玩法卡**、**場地圖卡（四角角牌／👍👎分邊／回收桶標籤／射月靶）**、**互動遊戲帶領卡**

## 🎵 主題曲：同真歌一樣嘅節奏

`js/lead.js` 嘅 `Music` 唔再係「每個音一樣長」嘅逼逼聲：

- 旋律以 **[頻率, 拍數]** 記譜（1＝四分音符、2＝二分音符），**句尾拖長、句與句之間換氣**——即係寄調 London Bridge 真正嘅節奏
- C 調・4/4，每小節配 **C／G 和弦**托底（同鋼琴版一樣），唔再得一條單音
- 開頭 **4 拍數拍先入**（第 1 拍聲重啲），全場一齊開聲唔會搶拍
- **三種速度**（慢 92／中 112／快 132 BPM），第一次帶用「慢」
- 卡拉OK高亮跟**實際音符時間**行（唔再用固定 interval，所以長短音都啱位）
- 🧰工具箱新增 **🥁 拍子器**（2／3／4 拍，80–140 BPM）：揚傘數拍、節奏模仿、跳格倒數都用得
- 排期全部用 `AudioContext.currentTime`（唔用 `setTimeout` 發聲），所以唔會甩拍

## 🎨 手工：領袖自己唔識做，都帶得

「先睇成品」只對識做嘅人有用——新領袖自己未做過，點示俾小朋友睇？所以 APP 將每樣手工拆成兩份教材：

- **俾小朋友睇**：成品示意圖（APP 畫出嚟，唔使領袖帶實物成品）＋做完一步舉手嘅規矩
- **俾領袖自己睇**：`js/craft.js` 內置 15 張自學卡 —物資與每人份量、開會前備料、逐步拆解（含尺寸）、關鍵摺法圖解、帶班拆法、最易錯位＋即刻補救、**零失敗後備版**、10/15/20 分鐘點剪、安全
- 未收錄嘅手工（包括自己加嘅環節）自動用「🧯 萬用六步救火」卡，唔會再出現「先睇成品」呢類無從下手嘅指示
- 每張卡可印 A4（🖨️ 教材庫 →「手工自學卡（領袖版）」）

入口：🎮活動 → 🎨跟我自學｜🧩準備卡 → 美勞環節 → 📚跟我自學｜▶️帶領畫面 → 成品示意圖｜📖手冊 → 🎨手工自學

## 🧰 「叫你做 → 教你點做」補漏層(`js/kit.js`)

全站掃過一遍：凡是 APP 叫領袖做一件事（執物資、檢查場地、頒獎、分工、通知家長、教章項），就一定要同時俾到「人手份量／做法／範本／後備」。呢一層提供：

- **📦 物資備料**：47 項物料寫明每人幾多、開會前點備、冇就改用咩（準備卡可摺疊睇，A4 教案自動附低）—包括**九宮格地貼、四角角牌、泡棉球**呢啲實體遊戲道具
- **🧭 五張執行檢查表**：戶外出發前・玩水安全・頒獎典禮・美勞前・**室內地貼／體能遊戲前**，各 10 項可剔；帶領畫面頂欄、工具箱、A4 都開到（剔咗會記住剔到邊，撳「完成今場」自動清返）
- **📣 家長訊息範本**：集會通知／物資收集／戶外須知／活動後多謝／缺席跟進，大括號自動填你旅團設定嘅時間・地點・電話，一撳複製
- **📅 低實今場日期**：行事曆逐格（或準備卡）填一次，`{date}`・星期・「之前一日話我知」全部自動計，唔使每日重打
- **👥 分工**：逐節填負責領袖（有旅團名單可揀），分享文字與 A4 教案都會跟住出
- **🏅 章項去邊度教**：團員章 6 項、小草蜢 7 範疇逐項附「去邊度教・點樣算過關・▶即刻開」
- **🖨️ 嘉許狀**：按名單一人一張（官方獎章證書仍需向總部申請，介面已註明）
- **⚖️ 影相私隱**：四句講清同意、範圍、唔想被影嘅隊員點處理

- **☔ 落雨／空氣差點算**：大會操・公園探索・夏水禮・運動會 4 場有室內後備版，用現有環節砌好，一撳存入「我嘅集會」—集會唔使取消
- **🗂️ 今場全套**：一疊印齊（教案＋今場檢查表＋已填主題嘅家長通知＋執袋單，人手按名單人數換算）
- **🤖 完場自動計數**：環節有標記嘅（唱主題歌・揚傘・整理領巾・誓詞・SFH／小草蜢七範疇）記錄完成時自動剔數，齊更會放音樂賀一賀；參加 4 次照住出席紀錄計，唔使自己寫表
- **🔍 全站搵嘢**：頂欄一框搜晒 30 張集會范本、15 張手工自學卡、物資點備、四張檢查表、A4 教材包、即玩遊戲、章項、手冊分頁；撳結果即跳到可以用嗰度（純內置，離線得）
- **📦 備份／還原**：⚙️設定一鍵匯出一個 JSON，換機前讀返（資料永遠只喺你部機）

> 設計原則：呢個 APP 係**帶集會**嘅工具，唔係行政系統—凡「記低、匯出、核对」呢類工作，能自動就自動，唔使領袖開表。小童軍重點係集會開心。

審計過程、判斷尺度（例如「準備紙筆」呢類成人即知嘅嘢唔算缺口）與修補對照表：`docs/gap-audit.md`。
