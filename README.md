# 🦗 小童軍集會助手 Grasshopper Hub

**© 2026 Scout System**

**由年度計劃到散會嗰刻**——規劃 → 執集會 → 當日帶領 → 團員進度追蹤。重點唔係將參考資料搬入 APP，而係將每個環節拆成「先做咩、圖解、可以照讀嘅口令、安全提示」，讓新領袖拎起手機就可以帶完整次集會。PWA 一個網址開即用、可加至主畫面、離線都用得。

## ⚡ 30秒開始

1. 開網址(GitHub Pages)→ 瀏覽器 menu →「加至主畫面」
2. 📅規劃 → 撳「▶ 帶領下次集會」→ 全螢幕 → 跟住綠色欄撳「下一個 ▶」就帶完成次集會
3. 集會完撳「✓ 記錄完成」→ 剔出席 → 進度自動入 🏅追蹤

## 🎨 手工：領袖自己唔識做，都帶得

「先睇成品」只對識做嘅人有用——新領袖自己未做過，點示俾小朋友睇？所以 APP 將每樣手工拆成兩份教材：

- **俾小朋友睇**：成品示意圖（APP 畫出嚟，唔使領袖帶實物成品）＋做完一步舉手嘅規矩
- **俾領袖自己睇**：`js/craft.js` 內置 15 張自學卡 —物資與每人份量、開會前備料、逐步拆解（含尺寸）、關鍵摺法圖解、帶班拆法、最易錯位＋即刻補救、**零失敗後備版**、10/15/20 分鐘點剪、安全
- 未收錄嘅手工（包括自己加嘅環節）自動用「🧯 萬用六步救火」卡，唔會再出現「先睇成品」呢類無從下手嘅指示
- 每張卡可印 A4（🖨️ 教材庫 →「手工自學卡（領袖版）」）

入口：🎮活動 → 🎨跟我自學｜🧩準備卡 → 美勞環節 → 📚跟我自學｜▶️帶領畫面 → 成品示意圖｜📖手冊 → 🎨手工自學

## 🔒 資料

- 團員資料/集會紀錄**只存在你自己裝置**(localStorage),不上傳
- Service Worker 離線快取,冇網都用得
- 此為非官方輔助工具,一切以香港童軍總會最新公佈為準
