# 🦗 小童軍集會助手

**© 2026 Scout System**｜非官方輔助工具，一切以香港童軍總會公佈為準。

新領袖開 APP → 撳一下 → **今場所有教材印齊** → 第二日拎起就用。

```
📦 集會套包（首頁）
 ├─ 🧑‍🏫 領袖套包：程序表・執袋單（已計人手）・環節帶領卡・手工說明・設場・家長通知・檢查表
 └─ 🧒 小朋友即用紙：剪線・摺線・描紅・塗色格 —— 印完即用，紙上冇說明書
```

## 三步開始

1. 開網址 → 瀏覽器 menu →「加至主畫面」（離線都用得）
2. 📦 套包 → 撳「🧑‍🏫 印領袖套包」同「🧒 印小朋友紙」（自動印夠人數）
3. 到場撳「▶ 即開帶領」，跟綠色領袖欄一步一步做；完場記出席，進度自動入 🏅追蹤

## 兩疊紙，點解要分開

以前手工紙同說明書印埋一疊，剪唔落手。而家：

| | 邊個睇 | 內容 |
|---|---|---|
| ✂️ 即用紙 | 小朋友 | 一張紙一件事：剪線／摺線／描紅／塗色格，A4 實際尺寸，印完即用 |
| 📚 自學卡 | 領袖 | 逐步拆解・最易錯位・補救・後備版・4–7 歲控場（開會前 3 分鐘睇） |

15 樣手工全部有即用紙；未收錄嘅手工自動跌入「今日我整咗……」萬用纸。

## 內容邊界

依據《小童軍活動指引》第三版訓練綱要撰寫，活動內容由本工具自行編寫，不搬官方套包版面。
支部事實已核實：4–7 歲・不設考驗・誓詞「我願參加小童軍，愛神愛人愛國家」・規律「小童軍日行一善」・口號「小童軍向前進」・銘言「前進」。
